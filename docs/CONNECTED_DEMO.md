# A connected demonstration / Uma demonstração conectada

## English

Prepare a session here, then explore printable invitation cards, explicit participant choices and a minimal public journal in the Python encounter kit.

Start with the optional observation template. The encounter kit adds alternative invitations and a validated choice → pause → resume → debrief flow. Its paused synthetic example has 30 seconds paused, 60 seconds active and one card skipped. Ending before start remains valid. The two plan formats are intentionally distinct; the kit exports to the public event journal through its tested adapter.

1. Run this repository's documented example and identify its main assumption.
2. Open [Évia · My Encounter / Meu Encontro](https://github.com/galafis/evia-inclusive-encounter-kit) and follow its bilingual installation guide.
3. Reproduce the committed scenario, change one assumption and explain the resulting difference.
4. Keep the report and exact input together. Describe what still needs a physical measurement or participant review.

The intended study context includes Unitree Go2 PRO. These demonstrations use synthetic data and do not command a robot or expose a private implementation.

## Português

Prepare aqui uma sessão; depois explore cartões imprimíveis de convite, escolhas explícitas do participante e um diário público mínimo no kit de encontros em Python.

Comece pelo modelo de observação opcional. O kit acrescenta convites alternativos e um fluxo validado de escolha → pausa → retomada → discussão. Seu exemplo sintético com pausa possui 30 segundos pausados, 60 ativos e um cartão pulado. Encerrar antes de começar continua válido. Os dois formatos de plano são distintos; o kit exporta para o diário público por meio de seu adaptador testado.

1. Execute o exemplo documentado deste repositório e identifique sua principal hipótese.
2. Abra [Évia · My Encounter / Meu Encontro](https://github.com/galafis/evia-inclusive-encounter-kit) e siga o guia bilíngue de instalação.
3. Reproduza o cenário publicado, altere uma hipótese e explique a diferença resultante.
4. Guarde relatório e entrada exata juntos. Descreva o que ainda precisa de medição física ou revisão com participantes.

O contexto pretendido de estudo inclui Unitree Go2 PRO. As demonstrações usam dados sintéticos, não comandam um robô e não expõem uma implementação privada.
